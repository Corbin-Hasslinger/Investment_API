## Atlas User Stories

** Version: 1.0
** Last Updated: August 2026

# Epic: Portfolio Management

## US-001
As an investor, I want to create a portfolio so that I can organize my investments.

### Acceptance Criteria

- Users can create multiple named portfolios.
- Portfolio names must be unique for each user.
- New portfolios persist after the user logs out.
- Newly created portfolios are accessible from the dashboard.

## US-002

As an investor, I want to add existing investment positions to my portfolio so that Atlas can calculate my portfolio performance and provide meaningful analysis.

### Acceptance Criteria

- Users can manually add a supported stock.
- Users can specify the number of shares owned.
- Users can specify the average purchase price.
- The system displays the current market price.
- The system calculates unrealized gain/loss in both dollars and percentage.
- The position appears in the selected portfolio.

## US-003

As an investor, I want to edit or remove positions so that my portfolio remains accurate.

### Acceptance Criteria

- Users can modify position information.
- Users can delete positions.
- Portfolio analytics update after changes.

# Epic 2: Portfolio Analytics

## US-004

As an investor, I want to view a summary of my portfolio so that I can quickly understand its current performance.

### Acceptance Criteria

- Total Portfolio Value
- Total Gain/Loss
- Total Return %
- Number of Holdings
- Largest Holding

## US-005

As an investor, I want to view how my portfolio is allocated across holdings so that I understand my diversification.

# Epic 3: Market Research

## US-006

As an investor, I want to search for a stock and view its current market information so that I can evaluate potential investments.

## US-007 

As an investor, I want to view financial information about a company so that I can better understand its business and fundamentals.

# Epic 4: AI Research

## US-008

As an investor, I want AI to explain my portfolio so that I better understand its strengths, weaknesses, and concentration.

## US-009

As an investor, I want AI to summarize a company using current financial information so that I can quickly understand the business before performing deeper research.

# Epic 5: Stock Screening

## US-010

As an investor, I want to filter stocks using customizable investment criteria so that I can discover companies matching my investing strategy.
